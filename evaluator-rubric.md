# evaluator-rubric.md — оценка работы сессии/спринта (0–2 по каждому измерению)

Запускать: после M2 (P05) и M3 (P08), либо при подозрении на халтуру. Оценивает Claude или Павел, НЕ сам Codex сразу после своей сессии.

| # | Измерение | Вопрос | Оценка 0–2 |
|---|---|---|---|
| 1 | Correctness | Реализация соответствует user_visible_behavior и ТЗ? | |
| 2 | Verification | Шаги verification реально запущены, evidence содержит команды и вывод? | |
| 3 | Scope discipline | Агент не вылезал за рамки фичи, не трогал чужой код? | |
| 4 | Reliability | Повторный прогон init.sh + pytest на чистом клоне зелёный? | |
| 5 | Maintainability | Код и записи понятны следующей сессии без объяснений? | |
| 6 | Handoff readiness | Новая сессия может продолжить только по артефактам репо? | |

**Заключение:** Accept (≥10 и нет нулей) · Revise (есть 1 у критичных 1,2,4) · Block (любой 0 у измерений 1 или 2).
