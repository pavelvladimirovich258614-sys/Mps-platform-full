# Решения видеовстречи (Павел × Сергей, запись «Платформа.mp4», 1ч 32м)

Это единственный источник правды о том, ЧТО мы строим. При любом споре «делать/не делать» — сверяемся сюда.

## 1. Что строим и как называем
- Делаем **«сайт нового образца»**: между собой называем **платформа-сайт**. Для клиентов это просто сайт. Журнал — это раздел внутри платформы, а не отдельный продукт (00:41–00:49).
- Название: **«Мир под солнцем»**, журнал о путешествиях турагентства «Под солнцем».
- Аналог-образец: Substack (лента, авторы, подписки), но заточенный под турфирму.
- Это будет сайт + позже мобильное приложение (QR-код на сайте, Android ≈300 ₽/мес за публикацию). Приложение — не сейчас (00:33–00:38).
- Домен старого сайта «купить тур» будет перенаправлен на платформу. Старый сайт не обновляем, он закрыт (00:38–00:39).

## 2. Роли и монетизация
- **Читатель (бесплатно):** читает, ставит лайки, пишет комментарии, оставляет отзывы, задаёт вопрос менеджеру (лимитировано), участвует в форуме.
- **Премиум (ПОТОМ, M5):** публикация своих постов, вопросы юристу, расширенные лимиты (создание тем и т.п.), общение с блогерами. Сергей: «Приобретите подписку — это чуть позже. Вначале его надо раскачать» (00:53–00:54). Рекламодатели придут сами, когда платформа станет живой.
- **Редактор/менеджер:** публикует статьи и фишки, модерирует отзывы и комментарии.
- **Админ (Павел + Сергей):** всё + статистика.

## 3. Разделы платформы (подтверждены на встрече)
1. **Лента** — большие публикации + короткие фишки, в конце поста сноска-CTA «Наш менеджер готов подобрать для вас тур» → ссылка в Telegram-бота (00:45–00:46).
2. **Фишки** — короткие лайфхаки.
3. **Отзывы** — любой клиент может оставить отзыв (премодерация). Сценарий: клиент вернулся из тура → бот присылает «Поделитесь отзывом» → пишет на платформе (00:44–00:45).
4. **Подписка** — email-рассылка, одно письмо в неделю.
5. **Вопрос-ответ** — вопрос менеджеру или юристу. Транслируется в Telegram (юристу/менеджеру в личку или чат), ответ возвращается на платформу (00:36–00:37). Менеджеру — вопросы свободно, юристу — позже за подписку.
6. **Форум по странам** (НОВОЕ, ключевое требование Сергея, 00:50–00:56): кнопка «Страны» → перечень (ОАЭ, Турция, Вьетнам, Таиланд, Китай, …) → внутри страны темы обсуждения → чат под темой. Поиск по темам, «одна-две-три темы бесплатно» — лимиты потом. Пример: «какую симку брать в ОАЭ» — отвечают живые люди, кто недавно был.
7. **О нас** — вся информация агентства со старого сайта (00:39–00:40).
8. **Видеообзоры «свежий взгляд»** (идея Сергея, 01:15–01:21): люди на местах (ОАЭ, Турция, позже Мальдивы) снимают свежие обзоры отелей по запросу туриста. На видео — логотип «Под солнцем» и дата съёмки. Подпись: «поступил запрос от туриста…». На платформе — отдельный тип контента.

## 4. Живость платформы
- Панель «кто онлайн» справа от ленты, возможность подписаться на людей (00:30–00:31, 00:38).
- Личный кабинет: онлайн/офлайн, режим «аноним» (00:34).
- Уведомления (звоночек): рассылки, ответы, личка (00:38).
- Лайки, комментарии + **реакции на комментарии**, чат/переписка между людьми (00:32–00:33).
- **ИИ-помощник в форуме** (рабочее имя «Иришка», 00:55–00:56): если на вопрос нет ответа — бот находит ответ (LLM) и отвечает под своим именем, чтобы чат не был мёртвым. Люди подхватывают диалог.

## 5. Юридическая обвязка (обязательно, 00:40–00:41)
Куки-баннер с принятием, политика обработки персональных данных, email, ИП + ИНН в футере, всё «как по закону». SEO-оптимизация, добавление в Яндекс/Google, чтобы находили.

## 6. Инструменты (решение по нейросетям, 01:00–01:08)
- **Кодекс (Codex)** — пишет проект, подписка активна до конца месяца. Приоритет: успеть костяк платформы.
- **MiniMax** (агент-нейронка, ключ по подписке) — потом подключается везде как ассистент: на сайт, в бота, автоматизация, карусели. Большое контекстное окно 1M.
- Instagram-автоматизация — через сервис-«переходник» с готовыми API (~2000 ₽/мес), НЕ через ChatPlace (дорого, не подходит).
- Аватар-девочка (виртуальная блогерша) для Instagram — отдельный трек, создаём свою (не клон реального менеджера, чтобы «не уволилась и не предъявила»), нужна позже.

## 7. Задачи вне платформы (бэклог соседних проектов, чтобы не потерять)
- **Бот «Под солнцем» (уже работает):** сделать скрытие контактов заявки — кто первый взял заявку, тому контакты в личку, остальные видят только статус «взята» (01:28–01:30). Павел обещал за 1–3 дня, до передачи менеджерам на тесты.
- Дожимные сообщения-кружочки в боте (человек неактивен 1–3 часа → кружочек/текст с фактом о путешествиях).
- Реферальная система в боте — продумать механику с маркетинговой точки зрения.
- Переименовать адрес канала (@…Taganka → под солнцем) — обсуждено, пока оставили.
- Агент IVA: ежедневная сводка инфоповодов по турбизнесу в 9:00 МСК, 1–3 черновика постов, без выдумывания цен/дат, приоритет Вьетнам/Таиланд/Азия. Сначала на согласование Сергею, потом публикация в канал.
- Один менеджер под брендом «под солнцем» ведёт колонку — Сергей менеджеров привлекать не хочет (контроль), значит контент делает ИИ + Павел.

## 8. Оплата и оформление
Работа по авансовой модели, перевод на **ИП Павла по реквизитам** (не на карту), формальный договор (ведение Telegram + создание сайта-платформы). Суммы Павел прикидывает и присылает.
