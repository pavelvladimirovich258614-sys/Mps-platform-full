# Дорожная карта МПС

Приоритет с встречи: «Сейчас приоритет — начинаем платформу» + Кодекс есть до конца месяца ⇒ костяк бекенда (M2) надо успеть в подписку Кодекса.

## M1 — Фронтенд-костяк (Claude Design) — ЧАСТИЧНО ГОТОВ
Готово: шапка, тёмная тема, роль «Читатель», Лента (публикация/фишка, «Читать дальше», лайк), Фишки, Отзывы с модерацией, Подписка, Вопрос-ответ (менеджер/юрист), комментарии с премодерацией, CTA-блоки в бота, floating CTA.
Доделать (промпт P00, блоки А–Е): форум по странам, панель «кто онлайн», профиль/личный кабинет, видеообзоры, «О нас» + юр-футер + куки, поиск, уведомления, реакции, QR-блок приложения, дизайн-полировка.
Выход: экспорт кода → `frontend/` в репо.
Срок-ориентир: 2–4 дня итераций в Claude Design.

## M2 — Ядро бекенда (Codex, сессии P01–P05)
P01 каркас (FastAPI+PG+Alembic+тесты+init.sh реально работает) → P02 auth+роли → P03 посты/лайки/видеообзоры → P04 отзывы+комментарии+реакции+модерация → P05 email-подписка + вопрос-ответ с Telegram-релеем.
Выход: API закрывает критерии приёмки 2–5, 9 (частично). Evaluator-прогон №1.
Срок-ориентир: 5–7 сессий (≈1 неделя).

## M3 — Сообщество (Codex, P06–P08)
P06 форум по странам → P07 Иришка (MiniMax) → P08 админка+статистика+уведомления+онлайн.
Выход: критерии 6, 9 полностью. Evaluator-прогон №2.
Срок: ≈1 неделя.

## M4 — Склейка и запуск (P09–P10)
P09: фронт пересаживается с localStorage на API (axios/fetch-слой, авторизация, состояния загрузки).
P10: деплой на VPS (nginx+systemd+certbot), перенос домена со старого сайта, sitemap/robots/OG/метатеги, Яндекс.Вебмастер + Search Console, куки-баннер и политика ПД проверены, бэкапы cron.
Выход: демо Сергею по всем 9 критериям приёмки. Передача менеджерам.
Срок: 3–5 дней.

## M5 — Монетизация и рост (после «раскачки», отдельное ТЗ)
Премиум-подписка + YooKassa, вопросы юристу за подписку, лимиты тем, Android-приложение (TWA, ~300 ₽/мес Play), рекламные места, лента «мои авторы», личные сообщения, аватар-блогерша для Instagram + автопостинг через API-переходник, автоматизация на MiniMax.

2. Бот: дожимные кружочки по неактивности.
3. IVA: ежедневные сводки 9:00 МСК на согласование Сергею.
4. Реферальная механика бота — концепт на согласование.
