# Аудит текущего фронтенда (прототип Claude Design «Мир под солнцем», 3 страницы)

## Что уже есть (подтверждено по offline-экспорту)
- Шапка: логотип-солнце, «МИР ПОД СОЛНЦЕМ / Журнал о путешествиях», переключатель тёмной темы, индикатор роли «Читатель» (есть переключение на «Редактор»).
- Сайдбар-навигация: Лента, Фишки, Отзывы, Подписка, Вопрос-ответ.
- Лента: hero-заголовок «Журнал о путешествиях БЕЗ ПРИКРАС», создание публикаций (Большая публикация / Короткая фишка), «Читать дальше →», удаление (для редактора), «Опубликовать в ленту».
- CTA-блоки: «Подберём тур под ваш бюджет → Подобрать тур», «Нужен тур, а не чтение? → Написать менеджеру», подпись «Материал подготовлен менеджерами агентства», «Хотите так же, но без планирования? → Подобрать тур в боте», floating CTA (переключатель showFloatingCta).
- Отзывы: форма с оценкой, «отзыв ушёл на проверку», статусы На проверке / Одобрить / Отклонить.
- Подписка: «Одно письмо в неделю. Ничего лишнего», подтверждение «письмо придёт в четверг».
- Комментарии: «публикуются после проверки менеджером», пустое состояние.
- Вопрос-ответ: вкладки Менеджер / Юрист.
- Футер-блок: «Под солнцем», «Бот подбора туров».
- Стиль: кремовый фон, тёмно-синий, золотые акценты, serif-заголовки — «премиальный журнал», Сергею подача зашла.
- Данные: localStorage (прототип), React.

## Чего не хватает (по решениям встречи) → закрывается промптом P00
1. Форум по странам (ключевое требование Сергея) — раздел, справочник стран, темы, сообщения, Иришка.
2. Панель «Сейчас на платформе» (онлайн-пользователи) справа от ленты.
3. Личный кабинет: вход (Telegram/email), профиль, аноним-режим, выход.
4. Видеообзоры «свежий взгляд» с датой съёмки и бейджем «по запросу туриста».
5. Раздел «О нас» + юридический футер (ИП/ИНН/политика ПД) + куки-баннер.
6. Поиск (по постам и темам форума) + отдельная кнопка «Поисковик туров» → бот.
7. Уведомления (звоночек).
8. Реакции на комментарии, ответы на комментарии.
9. Блок QR «Установить приложение» (заглушка «скоро» до M5).
10. Пустые/загрузочные состояния под будущее API, мобильная адаптивность всех новых блоков.

## Технические замечания к экспорту (для P09)
- Вся логика на localStorage → в P09 заменяется API-слоем; компоненты сохранить, вынести данные в hooks (useApi).
- Роль переключается кликом в шапке без авторизации — в проде роль приходит из /me, переключатель остаётся только в dev-режиме.
- Кнопка Save/варианты — артефакты редактора Claude Design, в экспорт не тащить.
