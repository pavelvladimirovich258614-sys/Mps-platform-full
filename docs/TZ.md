# Техническое задание: платформа «Мир под солнцем» (v1.0)

## 1. Цель продукта
Единая точка входа для клиентов турагентства «Под солнцем»: журнал о путешествиях + сообщество + воронка в Telegram-бота подбора туров. Аналог по механике — Substack (лента, авторы, email-подписка), но контент и функции заточены под туризм. Одна цель всей экосистемы: привлекать клиента на платформу, дальше воронка ведёт его в бота и к менеджеру.

## 2. Пользователи и роли
| Роль | Возможности |
|---|---|
| Гость | читает ленту/фишки/отзывы/форум, видит CTA «подобрать тур» |
| Читатель (регистрация) | + лайки, комментарии (премодерация), отзыв, 1 вопрос менеджеру без лимита ожидания, участие в форуме, создание до 3 тем, профиль, аноним-режим |
| Премиум (M5, выключено) | + публикации, вопросы юристу, безлимит тем, ЛС блогерам |
| Редактор | + создание/редактирование публикаций и фишек, модерация отзывов и комментариев, ответы на вопросы |
| Админ | всё + статистика, управление пользователями, рассылка |

Регистрация: email + код подтверждения ИЛИ вход через Telegram (Telegram Login Widget) — второй вариант приоритетный, т.к. вся аудитория уже в Telegram-боте.

## 3. Функциональные блоки

### F-A. Лента и публикации
- Два типа: «большая публикация» (заголовок, обложка, полный текст, «Читать дальше») и «короткая фишка».
- Третий тип: **видеообзор** — видеофайл/ссылка, название отеля, страна, дата съёмки (обязательное поле, выводится на карточке), бейдж «по запросу туриста» (опционально), водяной знак-логотип накладывается при загрузке или требуется в самом видео.
- В конце каждой публикации — CTA-сноска «Наш менеджер готов подобрать для вас тур →» (ссылка на бота, настраивается в админке).
- Лайки (1 на пользователя), счётчик просмотров.

### F-B. Отзывы
Форма: имя, оценка (1–5), текст, опционально фото. Статусы: на проверке → одобрен/отклонён (модерация редактором). Публичная страница показывает только одобренные.

### F-C. Комментарии
Под публикациями. Премодерация («публикуются после проверки менеджером» — уже в прототипе). Реакции на комментарии (👍❤️🔥 …). Ответы (1 уровень вложенности достаточно).

### F-D. Email-подписка
Поле email → подтверждение (double opt-in) → еженедельный дайджест (четверг): новые публикации + фишки недели. Отправка через Unisender Go. Отписка по ссылке в письме (обязательна по закону).

### F-E. Вопрос-ответ
Две очереди: «Менеджеру» и «Юристу». Вопрос с платформы → сообщение в Telegram (в рабочий чат менеджеров / юристу в личку через бота) → ответ командой/reply в Telegram → возвращается на платформу и в уведомления пользователя. Юрист в M2 виден, но помечен «скоро» (реально включаем, когда договоримся с юристом; за подписку — M5).

### F-F. Форум по странам
Справочник стран (флаг, название, порядок). Внутри страны — темы (title, автор, счётчик сообщений, поиск по темам). Внутри темы — сообщения в хронологии. Лимит: читатель создаёт до 3 тем (конфиг). ИИ-помощник «Иришка»: если тема без ответа N минут (конфиг, старт 30 мин) — генерирует полезный ответ через LLM (MiniMax API), публикует от аккаунта-помощника с пометкой «ИИ-помощник». Стоп-темы: цены/юридические гарантии — «Иришка» отвечает «уточню у менеджера» и создаёт вопрос в F-E.

### F-G. Профили и «живость»
Профиль: аватар, имя, о себе, страны где был. Онлайн-статус (websocket или поллинг last_seen ≤ 2 мин), переключатель «аноним». Панель «Сейчас на платформе» в ленте. Подписка на пользователей (лента «мои авторы» — M3+). Уведомления-звоночек: ответ на вопрос, ответ в теме, одобрение отзыва/комментария.

### F-H. Интеграция с ботом «Под солнцем»
- Кнопки «Подобрать тур →», «Написать менеджеру →» ведут в бота (deep-link с параметром source=platform для аналитики).
- Клиенту после закрытия заявки в боте приходит приглашение оставить отзыв на платформе (ссылка с токеном — отзыв привязывается без повторной регистрации).

### F-I. Админка и статистика
Модерация (отзывы, комментарии), CRUD публикаций, справочник стран, пользователи (бан), настройки CTA-ссылок. Статистика: пользователи всего/активные 30д, новые 7д/30д, подписчики рассылки, вопросы открыто/закрыто, топ публикаций.

### F-J. Юридическая обвязка и SEO
Куки-баннер, страница «Политика обработки персональных данных», футер: ИП, ИНН, email, «О нас». SSR/пререндер публичных страниц, sitemap.xml, robots.txt, OpenGraph, микроразметка Article, регистрация в Яндекс.Вебмастер и Google Search Console. Домен переносится со старого сайта.

## 4. Нефункциональные требования
- Публичные страницы открываются < 1.5 c на мобильном; работа без VPN из РФ (хостинг — VPS Павла, Нидерланды; при проблемах со скоростью — CDN/перенос в РФ, решение на M4).
- Мобильная адаптивность обязательна (большинство придёт из Telegram с телефона).
- Все тексты интерфейса — русский.
- Хранение ПД в соответствии со 152-ФЗ (минимизация: email, имя, telegram_id).
- Резервные копии PostgreSQL ежедневно (pg_dump + cron, хранить 14 дней).

## 6. Вне рамок v1 (M5+)
Платная подписка (YooKassa), Android-приложение (TWA), рекламные места, личные сообщения между пользователями, публикации от читателей, полнотекстовый поиск по всему сайту (в v1 — поиск только по темам форума и заголовкам постов).

## 7. Критерии приёмки v1 (демо Сергею)
1. Захожу с телефона по домену без VPN → вижу ленту с публикациями и фишками.
2. Регистрируюсь через Telegram в 2 клика → ставлю лайк, пишу комментарий → комментарий появляется после одобрения в админке.
3. Оставляю отзыв → редактор одобряет → отзыв на странице отзывов.
4. Подписываюсь на рассылку → получаю письмо подтверждения → в четверг приходит дайджест.
5. Задаю вопрос менеджеру → вопрос падает в Telegram-чат → менеджер отвечает reply → ответ виден мне на платформе + уведомление.
6. Захожу в форум → ОАЭ → создаю тему «какая симка?» → через 30 мин отвечает Иришка → второй пользователь дописывает.
7. В футере — политика ПД, ИНН; куки-баннер при первом входе; страница «О нас».
8. Нажимаю «Подобрать тур» → попадаю в бота «Под солнцем».
9. Админ видит статистику и модерирует контент.
